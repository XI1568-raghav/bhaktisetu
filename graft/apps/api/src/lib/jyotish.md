# apps\api\src\lib\jyotish.ts

- deg · function · L20-L24 — Normalizes any angle into the [0, 360) range so all longitude math stays sign- and quadrant-stable.
- julianDay · function · L26-L41 — Converts a UTC birth timestamp into a Julian Day number, the time base every astronomical formula in the file consumes.
- lahiriAyanamsa · function · L43-L46 — Computes the Lahiri ayanamsa (tropical-to-sidereal zodiac offset) with linear precession drift from its 23.85° J2000 epoch value.
- meanObliquity · function · L49-L58 — Evaluates the Meeus 22.2 polynomial for Earth's mean axial tilt, needed to convert sidereal time into an ecliptic ascendant.
- sunLongitudeTropical · function · L62-L72 — Computes the Sun's tropical longitude via mean longitude plus the equation-of-center correction, anchoring both the chart's Sun and the geocentric correction for other planets.
- moonLongitudeTropical · function · L74-L94 — Computes the Moon's tropical longitude by adding the dominant lunar perturbation terms to its mean longitude, accurate enough for sign-stable natal placement.
- rahuLongitudeTropical · function · L99-L108 — Computes the mean ascending lunar node (Rahu) via the Meeus 47.7 regression polynomial; Ketu is later derived as Rahu + 180°.
- PlanetMean · interface · L122-L125 — Data holder pairing a planet's J2000 mean longitude with its per-century mean motion for linear ephemeris extrapolation.
- meanHeliocentricLongitude · function · L135-L139 — Linearly extrapolates a planet's heliocentric mean longitude from its J2000 epoch value and mean motion.
- planetGeocentricLongitudeTropical · function · L150-L165 — Approximates geocentric longitude by swinging Mercury/Venus around the Sun within their max elongation while treating outer planets' heliocentric longitude as geocentric.
- planetLongitudeSidereal · function · L167-L169 — Converts a planet's tropical geocentric longitude to sidereal by subtracting the Lahiri ayanamsa.
- gmstHours · function · L174-L184 — Computes Greenwich mean sidereal time in hours from the Julian Day, including the UT-day fraction scaled by the sidereal/solar rate.
- localSiderealTimeDeg · function · L186-L189 — Converts GMST to local sidereal time in degrees by adding the birth-place east longitude.
- lagnaLongitudeSidereal · function · L195-L207 — Derives the true sidereal Ascendant (Lagna) from local sidereal time, birth latitude, and obliquity via the standard atan2 ascendant formula with quadrant resolution.
- rashiIndex · function · L211-L213 — Maps a sidereal longitude to its zodiac sign index (0–11) by dividing the ecliptic into twelve 30° rashis.
- rashiDegree · function · L215-L217 — Returns a body's degree within its rashi by subtracting the sign's 30°-multiple start from the sidereal longitude.
- nakshatraIndex · function · L219-L222 — Maps a sidereal longitude to one of the 27 equal-span nakshatras.
- nakshatraPada · function · L224-L228 — Determines which quarter (pada 1–4) of a nakshatra a sidereal longitude falls in.
- bhavaFromLagna · function · L231-L235 — Assigns a whole-sign house number (1–12) by counting signs from the Lagna's rashi to the planet's rashi.
- PlanetPosition · interface · L239-L245 — Data holder for one chart body: its sidereal longitude plus derived rashi index, degree-in-sign, and bhava.
- VedicChart · interface · L247-L252 — Data holder for a complete natal chart: Julian Day, ayanamsa, Lagna position, and all nine graha positions.
- buildVedicChart · function · L254-L300 — Orchestrates the full natal chart: converts birth data to sidereal longitudes for all nine grahas plus Lagna, then resolves each body's rashi, degree, and whole-sign bhava.
