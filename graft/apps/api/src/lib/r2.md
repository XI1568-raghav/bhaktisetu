# apps\api\src\lib\r2.ts

- UploadResult · interface · L56-L62 — Result shape for uploads, reporting success/failure plus the stored key, public URL, or a skipped flag when no storage backend is configured.
- r2PublicUrl · function · L64-L67 — Builds the public URL for an R2 object, preferring the configured custom CDN base over the default cloudflarestorage.com bucket URL.
- uploadToR2 · function · L69-L107 — Uploads a media object to R2 when configured, otherwise to Supabase Storage, returning the public URL or a skipped/error result so callers need not know which backend is active.
- presignR2Url · function · L112-L130 — Generates a time-limited signed URL for reading a private object from whichever storage backend is active, returning null when signing fails or no backend exists.
- presignR2Upload · function · L140-L172 — Issues a signed PUT URL so browsers can upload media directly to storage without proxying through the API, also returning the eventual public URL and which backend signed it.
- deleteFromR2 · function · L174-L186 — Deletes an object from the active storage backend, reporting success as a boolean so callers can treat R2 and Supabase deletion uniformly.
- publicUrlFor · function · L188-L193 — Resolves the public URL for a stored key from whichever backend is enabled, returning null when no storage is configured.
