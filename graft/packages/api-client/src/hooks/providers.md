# packages\api-client\src\hooks\providers.ts

- Astrologer · interface · L10-L22 — Describes an astrologer listing/profile (specializations, languages, rating, per-minute price) returned by the astrology API for display and booking flows.
- useAstrologers · function · L24-L45 — Fetches the paginated astrologer directory, keyed in the query cache by specialization/language filters so each filter combination is cached separately.
- useAstrologer · function · L47-L58 — Fetches a single astrologer's profile by id, suppressing the request entirely when no id is available.
- useHoroscope · function · L60-L71 — Fetches the horoscope for a given rashi (zodiac sign), suppressing the request when no rashi is selected.
- WellnessInstructor · interface · L75-L84 — Describes a wellness instructor (specializations, rating, hourly rate) for instructor listings and booking.
- WellnessSession · interface · L86-L97 — Describes a bookable wellness session (type, duration, level, instructor, start time) for session catalogs and scheduling.
- WellnessProgram · interface · L99-L106 — Describes a multi-day wellness program (duration in days, type) for program listings.
- useWellnessInstructors · function · L108-L122 — Fetches the list of wellness instructors from the wellness API.
- useWellnessSessions · function · L124-L136 — Fetches the catalog of available wellness sessions.
- useWellnessPrograms · function · L138-L150 — Fetches the catalog of wellness programs.
- Gaushala · interface · L154-L161 — Describes a gaushala (cow shelter) with location and cow count for shelter listings.
- Cow · interface · L163-L171 — Describes an individual cow (breed, age, health, adoption status) for adoption browsing.
- AdoptionPlan · interface · L173-L179 — Describes a monthly cow-adoption subscription plan with price and benefits.
- useGaushalas · function · L181-L189 — Fetches the list of gaushalas (cow shelters).
- useCows · function · L191-L199 — Fetches the list of cows available across gaushalas.
- useAdoptionPlans · function · L201-L213 — Fetches the available cow-adoption subscription plans.
- PriestDashboard · interface · L217-L224 — Aggregates a priest's at-a-glance metrics: today's bookings, daily/monthly earnings, rating, and pending video uploads.
- PriestBooking · interface · L226-L236 — Describes a priest's scheduled puja booking including devotee, schedule, status, amount, and whether the ritual video was uploaded.
- PriestPayout · interface · L238-L244 — Describes a payout made to a priest, with amount, status, and optional link to the originating booking.
- usePriestDashboard · function · L246-L254 — Fetches the priest's dashboard summary metrics for the priest portal home view.
- usePriestBookings · function · L256-L270 — Fetches the priest's assigned bookings with total count for the priest portal booking list.
- usePriestPayouts · function · L272-L286 — Fetches the priest's payout history with total count.
- usePriestProfile · function · L288-L296 — Fetches the priest's own profile for the priest portal.
- AdminDashboard · interface · L300-L306 — Aggregates platform-wide admin metrics: users, bookings, revenue, active temples, and pending approvals.
- AdminUser · interface · L308-L316 — Describes a platform user as seen by admins (contact info, role, status) for user management and approval queues.
- useAdminDashboard · function · L318-L326 — Fetches platform-wide summary metrics for the admin dashboard.
- useAdminUsers · function · L328-L343 — Fetches the admin user list, keyed in the query cache by role/search filters so each filter combination is cached separately.
- useAdminPendingApprovals · function · L345-L359 — Fetches the queue of users awaiting admin approval.
- useAdminRevenue · function · L361-L369 — Fetches revenue reporting data for the admin portal.
