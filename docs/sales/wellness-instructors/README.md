# Wellness Instructor Onboarding — R-Q1-S-010

Q1 sales artifact bundle for onboarding 5 verified wellness instructors (yoga + Ayurveda) by month-3.

## Goal

Onboard 5 vetted wellness instructors live on Darshya by end of month 3 of Q1. Mix: 3 yoga, 2 Ayurveda (acceptable: 4 yoga + 1 Ayurveda or 2 yoga + 3 Ayurveda, but not skewed beyond that).

Funnel ratio applied: 15 candidates → 5 live (33% conversion target).

## Files in this bundle

| File | Purpose |
|---|---|
| `README.md` | This overview |
| `target-list.csv` | 15 candidates with full schema (name, discipline, credentials, IG, etc.) |
| `target-list-research.md` | Discovery notes per candidate (why picked, lineage) |
| `vetting-rubric.md` | 6 gates every instructor must pass |
| `outreach-email-template.md` | Email body + 2 subject lines + 3 objection responses + cadence |
| `outreach-instagram-dm.md` | IG opener + follow-up + 45-sec voice-note script |
| `intake-form-spec.md` | Form fields → future `wellness_instructors` table mapping |
| `crm-tracking.csv` | Pre-seeded 15 leads (status=lead, owner=founder) |
| `acceptance-harness.md` | How to verify the bundle is intact (automated + manual) |

## Founder workflow

1. **Day 0**: Read `vetting-rubric.md` + both outreach templates. Adjust voice where needed.
2. **Day 1-3**: Begin IG DM outreach (primary channel for wellness instructors). Send tier-A targets first.
3. **Day 5+**: Follow-up bumps per cadence in DM script.
4. **Day 7-14**: Email follow-ups for any instructor whose website lists email.
5. **Day 10-30**: 20-min intro calls with respondents. Score per Gate 5.
6. **Day 14-45**: Send credential request + sample class link request (Gates 1-3).
7. **Day 30-60**: MOU sent to those passing Gates 1-5.
8. **Day 45-75**: Approved instructors fill intake form. Go live on platform.
9. **Day 75-90**: First 5 instructors live, taking bookings.

## Why this matters (Q1)

- Q1 strategy needs wellness vertical present before market validation. 5 instructors = minimum viable supply.
- Wellness instructors typically have own funnel (IG following) — boosts our SEO + social proof on launch.
- Ayurveda specifically targets NRI segment (higher LTV) — even 2 BAMS practitioners differentiates Darshya from pure-yoga competitors.

## Out of scope this item

- Live outreach by agent (founder must do this — relationship-driven)
- Final legal MOU (template ships; formal legal review queued separately)
- Booking UI for instructor sessions
- Payment splits implementation (instructor sets price; 0% Q1 platform fee)
- Astrology, kirtan, other non-yoga/non-Ayurveda wellness verticals (separate roadmap items)
