# Wellness Instructor Outreach — Instagram DM Script (R-Q1-S-010)

90% of wellness instructors are discovered + reachable via Instagram, so DM is the primary channel for this cohort. Email is the formal follow-up.

## Opener DM (≤300 chars, DM length-safe)

> Hi {firstName} — I'm {founderFirstName}, founder of Darshya (India devotional + wellness platform). Loved your recent {sample_referenced}. Putting together a 5-instructor founding cohort for Q1 — no platform fee, you set price, global student funnel. Open to a 20-min call?

Character count: ~290 with typical {firstName} and {sample_referenced} substitutions.

## Follow-up DM (Day 5 if no response)

> Hey, floating this back up — happy to send more detail or skip the call and start with email. No rush, just don't want it to get buried.

## Voice-note script (45 seconds, for high-priority Tier-A targets)

For tier-A instructors (KPJAYI-authorized, RIMYI Junior+, BAMS w/ 10+ yrs, Bihar School senior), use a voice note instead of text DM after the opener. Higher response rate per benchmarks.

**Script (read at conversational pace, ~45 sec):**

> Hey {firstName}, this is {founderFirstName} — founder of Darshya. I sent you a DM earlier but wanted to come through voice because what I'm building is genuinely interesting and a text message doesn't really do it justice. Quick context: we're building a devotional + wellness platform for the global Hindu diaspora and India-domestic seekers. For Q1 we're picking 5 founding-cohort instructors across yoga and Ayurveda — heavy emphasis on credentials and teaching depth, which is why I'm reaching out to you specifically. The deal is: no platform fee at all in Q1, you set your own price and schedule, we handle all the tech. If a 20-minute call this week or next sounds doable, I'll send my Calendly. Either way, thank you for the work you put out.

## Cadence

- Day 0: Opener DM (text).
- Day 2-3: For tier-A only — voice note follow-up if no reply yet.
- Day 5: Text follow-up bump.
- Day 10: Switch channel to email if instructor's website lists one.
- Day 30: Drop, re-list for Q2 with new angle.

## Reply-handling notes

- If reply says "send me email" → trigger email template within 12 hours; voice notes if requested next.
- If reply has objections → use 3 objection responses from `outreach-email-template.md` adapted to short-form text.
- If reply is positive → send Calendly link + 1 sentence reaffirming no-exclusivity, no-platform-fee Q1.

## Tracking

CRM `next_action` column tracks current channel + day-of-cadence per instructor. Founder updates daily.
