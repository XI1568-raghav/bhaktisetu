# Wedding Vendor Onboarding Playbook

> **Roadmap item**: R-Q4-S-009 (P2) · **Authored**: 2026-06-13
> **Target**: 65 verified vendors = 30 photographers + 20 caterers + 15 decorators by month-11 close
> **Source pool**: 130 prospects in `seeds/wedding-vendors-prospects.csv` (2× target)

## Per-category verification rubric

### Photographers (30 target)

- [ ] Portfolio review: ≥3 full weddings shot, at least 1 in last 12 months
- [ ] References: 2 past clients reachable by WhatsApp; both 5★ verbal recommend
- [ ] Equipment: dual-body shooter minimum (Sony A7-series / Canon R-series acceptable)
- [ ] Insurance: optional but a plus (Bajaj / ICICI Lombard event-photographer policy)
- [ ] Delivery SLA: edited gallery within 60 days; teaser within 7 days
- [ ] Pricing: published rate card (range OK); no "DM for price" black-box vendors

### Caterers (20 target)

- [ ] FSSAI license: current + display able (mandatory — no FSSAI = auto-reject)
- [ ] Kitchen audit: founder or local agent visits kitchen, photographs hygiene
- [ ] Tasting: at least 5-dish sample tasting before contract; pay tasting cost
- [ ] Past events: 3 wedding references (200+ pax) reachable
- [ ] Pure-veg vs mixed: explicitly logged in vendor row notes
- [ ] Regional cuisine specialization: logged (Bengali / Marwari / Punjabi / South Indian / Hyderabadi etc)

### Decorators (15 target)

- [ ] Past-event photos: 3 mandap + 3 stage decor sets, dated
- [ ] Insurance: event liability minimum ₹50L coverage (mandatory for any pyrotechnics / heavy structures)
- [ ] Crew size: minimum 8-person installation team; ask explicitly
- [ ] Floral source: local vs imported (price tier signal)
- [ ] Setup time SLA: must complete day-before-wedding by 8pm
- [ ] Tear-down inclusive: yes/no; logged in notes

## Commission / rev-share structure (proposed)

| Category | Darshya commission | Vendor net | Notes |
|---|---|---|---|
| Photographer | 12-15% on first booking, 8-10% thereafter (indicative — founder approves final) | 85-92% | Vendor invoices client direct; we pay vendor T+7 of event date |
| Caterer | 8-10% flat (indicative — founder approves final) | 90-92% | Per-plate gross; min commitment 200 pax/event |
| Decorator | 10-12% flat (indicative — founder approves final) | 88-90% | Includes platform listing, lead-routing, escrow |

- Founder discretion: waive first-event commission for early-bird signups (first 10 per category)
- Platform fee: ₹0 onboarding; commission only on confirmed bookings
- Payment: UPI / IMPS / bank transfer T+7 of event date; escrow held in Razorpay route

## Red-flag list (auto-reject during pre-screen)

- [ ] No GST number when revenue is clearly >₹40L/year (tax non-compliance risk)
- [ ] No portfolio / Instagram looks dormant (last post >6 months)
- [ ] No phone / only DM contact (ghost vendor pattern)
- [ ] Asks for upfront platform fee before verification (scam signal)
- [ ] Cannot produce ANY past-client reference
- [ ] Negative reviews on WeddingWire / WedMeGood / Google with consistent theme
- [ ] FSSAI mandatory for caterer — no exception
- [ ] Insurance mandatory for decorator — no exception
