## Goal

By Q4-end: 5 B2B SaaS pilot customers signed paying ₹999-₹4,999/mo. Total ₹15K-25K MRR direct + cross-sell donations + commission.

## 5 target customer types

### Type 1 — Temple chain (1)

Single org operating 5-20 temples (e.g. Iskcon Ratha Yatra committee, Sringeri Mutt branches). Pays Pro tier ₹2,999/mo for chain-wide donor mgmt.

### Type 2 — Ashram network (1)

E.g. Art of Living, Isha Foundation Bengaluru chapter, Sivananda Yoga. Pays Pro tier for ashram-side puja booking + recurring donor mgmt.

### Type 3 — Matha network (1)

E.g. Pejawar Mutt, Sringeri Mutt, Raghavendra Mutt chapters. Pays Pro tier for donor + devotee mgmt across chapters.

### Type 4 — Single high-volume temple (1)

E.g. Vaishno Devi Shrine Board (top of Hindu pilgrim revenue). Pays Enterprise tier ₹4,999/mo for full donor CRM + 80G auto + analytics.

### Type 5 — Diaspora temple federation (1)

E.g. Hindu Federation Canada, BAPS USA. Pays Pro tier for member-temple donor mgmt.
