```
"Hare Krishna {Name} ji, main {founder name} se Bhaktisetu Foundation
bol raha hoon. Aap ke {temple} ko ek email bheji thi kuch hafte pehle,
possible hai aap tak nahi pahuncha. 2-3 minute hain mere paas?

Bhaktisetu Foundation verified-temple platform hai — devotees ko
remote puja booking, video proof, 80G receipt. Aapke temple ko
60-80% commission, no upfront fee.

Main yeh phone ka follow-up kar raha hoon kyunki ISKCON specifically
hum carefully approach kar rahe hain — aapke sampradaya ka rigour
humare verification standard se match karta hai.

15-min ka call possible hai is hafte? Aapke convenient samay par.
Calendly link bhej dunga ya WA pe time set kar lete hain.

Hare Krishna."
```

If TP not available → ask for callback OR speak to admin (still log).
