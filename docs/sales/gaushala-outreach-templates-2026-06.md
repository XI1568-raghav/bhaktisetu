## Personalization variables (per send)

Fill ALL before send:

1. `{gaushala_name}` — official trust name
2. `{decision_maker}` — manager / trustee / president name + title
3. `{location}` — city + state
4. `{cow_count}` — approximate count (verifies you've researched)
5. `{specific_seva}` — named program (e.g. "your Govardhan parikrama seva", "the cow-rescue work after Chitrakoot floods")
6. `{founder_name}` — sender name
7. `{calendly_url}` — 15-min booking link

## Variant 1 — Heritage cluster (Mathura / Vrindavan / Pathmeda)

**Audience**: Traditional Vaishnav / Shakta gaushalas. Bhakti tone. Dharma-first framing. Hindi greeting + closing.

**Subject (HI)**: प्रणाम — {gaushala_name} के लिए darshya.online पर adopt-a-cow seva platform

**Body (~170 words)**:

```
प्रणाम {decision_maker} जी,

जय श्री राधे / हरि बोल।

मैं {founder_name}, Bhaktisetu Foundation (darshya.online) का संस्थापक हूँ। हम urban devotees के लिए recurring devotional-seva platform चलाते हैं — already adopt-a-temple subscription में ~50 temples हैं।

{location} के बारे में पढ़ा कि आपकी {gaushala_name} में ~{cow_count} गायें हैं और {specific_seva} की seva चलती है। यह exactly वो depth है जो urban donors में emotional connect बनाती है।

**हमारी offer आपके gaushala के लिए**:
- 92% disbursement आपको (8% platform fee — Razorpay + Foundation legal cover)
- हर donor को auto 80G receipt + masik impact report PDF
- public adoption page (donor-name list opt-in से)
- Cross-sell access to existing temple-adopter donors

**आप से चाहिए**: 80G certificate copy + 1 onboarding call (30 मिनट) + masik cow-count update (1 पन्ना)।

15-min परिचय call अनुकूल समय पर: {calendly_url}

गौ-माता का आशीर्वाद,
{founder_name}
Founder, Bhaktisetu Foundation
darshya.online
```

## Personalization checklist

Before EVERY send, founder fills:

- [ ] `{gaushala_name}` — verified spelling + legal trust name
- [ ] `{decision_maker}` — name + title (President / Manager / Trustee) — `unknown` if not found
- [ ] `{cow_count}` — researched (NOT guessed) from gaushala website / phone call / public registry
- [ ] `{location}` — city + state
- [ ] `{specific_seva}` — ONE named program / recent activity / seva — proves you researched the gaushala (NOT a generic Reply Guy message)

If any variable cannot be filled with VERIFIED info, drop the prospect and move to next — better 10 personalized than 30 generic.

## Platform fee disclosure

All 3 variants EXPLICITLY disclose 8% platform fee in the offer block. This is non-negotiable for trust — gaushala managers will ask anyway. Front-loading the fee builds credibility.
