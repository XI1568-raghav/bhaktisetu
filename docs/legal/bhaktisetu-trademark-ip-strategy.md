# Bhaktisetu Trademark + IP Strategy

> Protection of Bhaktisetu brand + AI Pandit IP + content moat. Pre-Series-A foundation.

## Why this matters

- Sri Mandir ($35M Series B) likely has filed trademark
- Bhaktisetu domain bhaktisetu.com secured
- AI Pandit RAG corpus is proprietary IP
- 250+ pillar SEO pages are content IP
- Brand recognition starting to build via Twitter + Reddit

## IP categories to protect

### 1. Trademarks

- "Bhaktisetu" word mark — Class 41 (Education), 42 (Tech), 45 (Religious services)
- "Bhakti Pro" subscription tier mark — Class 41 + 45
- "Verified Pandit" service mark — Class 45
- Logo + tagline mark — Class 45
- Domain bhaktisetu.com — already secured
- Social handles — claimed across Twitter, LinkedIn, Instagram, YouTube

**Registration**: Trademark Registry India (Class 45 priority); Q3 file 4 marks for ₹15K total filing fees + ₹50K legal counsel. WIPO international filing for US/UK/CA/AU Q4.

### 2. Copyrights

- Original blog content (250+ pillar pages) — copyright auto-attaches
- Sanskrit translations (custom by Bhaktisetu pandits) — copyright on translation expression
- Photo + video assets (founder + temple shoots) — copyright auto-attaches
- AI Pandit conversational AI output (debatable IP) — open question Indian law

**Strategy**: License all original content under CC-BY-SA-NC (non-commercial use OK, attribution required). Premium content stays proprietary. Indian copyright auto-attaches without registration.

### 3. Trade Secrets

- Pandit network internal documentation (not public)
- KYC verification process (operational secret)
- Customer + investor data (confidential per DPDP)
- Internal financial models (founder/board only)

**Strategy**: NDA in every contractor + vendor + partner agreement. Multi-factor auth on all internal docs. Quarterly access review.

### 4. Patents (Defensive)

- AI Pandit RAG corpus + multi-language Sanskrit grounding (potentially patentable as composition + method)
- Video proof verification workflow (potentially patentable as method)
- NRI dual-currency reconciliation (potentially patentable, less novel)

**Strategy**: Defensive disclosure rather than patent filing. Maintain priority through publication + technical blog posts. Patent filing only if competitor copies + threatens revenue.

## Risk + mitigation

- **Risk**: Sri Mandir or other competitor files Bhaktisetu-similar trademark
- **Mitigation**: File first, claim Indian Class 45 priority
- **Risk**: Open-source AI tools commoditize AI Pandit advantage
- **Mitigation**: Curated Sanskrit corpus + pandit human-augmented Q&A is the moat, not the LLM
- **Risk**: Content scraped by competitors
- **Mitigation**: Cloudflare DDoS + rate-limit + content fingerprinting; license terms make scraping legal liability

- Trademark renewal every 10 years (per Indian law)
- WIPO filings renew per international Madrid protocol
- Copyright lasts 60 years after author's death (per Indian Copyright Act)
