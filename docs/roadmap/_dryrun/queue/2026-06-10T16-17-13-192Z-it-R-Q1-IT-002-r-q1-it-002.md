## Fail-loud guard requirement

In `cron-auth.ts`:
```ts
if (!process.env.CRON_AUTH_TOKEN) {
  console.error('[FATAL] CRON_AUTH_TOKEN env var unset — refusing all cron requests');
  return res.status(401).json({ error: 'cron_auth_misconfigured' });
}
```

Never default to permissive. Never skip in dev. Doctrine: explosion > silent pass.
