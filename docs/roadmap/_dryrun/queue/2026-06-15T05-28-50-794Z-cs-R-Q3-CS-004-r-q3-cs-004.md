## Deliverables

### 1. Decision-tree doc
`docs/agent-reports/cs/wa-bot-triage-decision-tree.md` with:
- Mermaid flowchart of triage flow (inbound → lang detect → intent match → confidence gate → respond OR escalate)
- Per-intent escalation thresholds table:

| intent | auto_respond | escalate_if | escalation_target | SLA |
|---|---|---|---|---|
| refund | yes (status query) | refund_amount > 5000 OR booking > 30d old | finance-cs | 4h |
| reschedule | yes | within 24h of booking | ops-cs | 2h |
| pandit_no_show | **never** | always | senior-cs + ops | 15min |
| language_mismatch | yes (offer lang switch) | user requests human | cs-tier1 | 1h |
| payment_failed | yes (retry link) | 2+ failures | finance-cs | 30min |
| otp_missed | yes (resend) | 3+ attempts | cs-tier1 | 30min |
| nri_timezone | yes (schedule callback) | callback >48h out | nri-cs | 24h |
| gift_booking | yes (FAQ) | custom request | cs-tier1 | 4h |
| group_booking | no — always human | always | sales | 2h |
| kyc | yes (doc upload link) | doc rejected | kyc-cs | 4h |

- Confidence gate rules: ≥0.7 auto, 0.4-0.7 propose macro + ask "is this what you meant?", <0.4 → human
- Lang fallback: detected lang ∈ {hi,en} → use native macro; ∈ {ta,te,bn,mr} → use EN macro + add disclaimer + flag `awaiting_native_review` (blocks on R-Q2-CS-003)
- Office-hours behavior: outside 9am-9pm IST, escalations queue with auto-ack message; pandit_no_show + payment_failed remain pageable
- Loop-prevention: max 3 bot turns then force human
