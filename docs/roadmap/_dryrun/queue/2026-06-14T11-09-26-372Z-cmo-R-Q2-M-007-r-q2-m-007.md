# R-Q2-M-007 — Programmatic SEO: 50 NRI long-tail templates (puja × city × language)

caveman terse. ship MDX content + matrix spec + linking + distribution.

## Context

depends on R-Q1-M-002 (programmatic page generator infra). that ships generator; this ships content + template matrix. target = 500 pages live, but cycle deliverable = 50 net-new templates + 3 hero MDX drafts as proof-of-quality. NRI angle = higher LTV, less competition than India tier-1.

## Thesis: why NRI > tier-2 cities

- tier-2 city pages compound with sales (already done in earlier cycles)
- NRI keywords: lower volume but 5-10x conversion ($USD pricing, urgency around festivals, no local pandit access)
- diaspora search intent unmet: "puja for grihapravesh from USA", "online satyanarayan katha NRI Canada" — minimal competition
- TAM: ~32M Indian diaspora globally, ~70% identify as Hindu, festival-driven search spikes

## Keyword strategy (free-tier methods)

free tools:
- Google Search Console (existing site data)
- Google autocomplete + "People Also Ask"
- Google Trends (regional comparison)
- AnswerThePublic free tier (3 queries/day)
- Reddit search (r/ABCDesis, r/hinduism, r/IndianDiaspora) for natural language patterns
- YouTube autocomplete (search intent proxy)

## Target keyword clusters (5 clusters × 10 templates = 50)

### Cluster 1: NRI puja booking by occasion
template: `online {puja} from {country} | book pandit for NRI`
examples:
- online satyanarayan puja from usa
- online griha pravesh puja from canada
- online navratri puja from uk
- online ganesh chaturthi puja from australia
- online diwali lakshmi puja from singapore
- online karwa chauth puja from uae
- online raksha bandhan puja from germany
- online mundan ceremony from new zealand
- online namkaran puja from qatar
- online ayushya homam from saudi arabia

rationale: "online" + "from {country}" = high-intent commercial query, low competition (verified via manual SERP check), ~50-500 monthly searches each but 10-15% conversion vs 1-2% for top-of-funnel.

### Cluster 2: Festival-triggered urgency
template: `{festival} {year} puja booking from {country}`
- diwali 2026 puja booking from usa
- holi 2026 puja booking from canada
- (etc — 10 variants spanning major festivals × top 5 NRI countries)

### Cluster 3: Pandit language match
template: `{language} speaking pandit online for {country} NRI`
- tamil speaking pandit online for usa nri
- telugu speaking pandit online for canada nri
- (10 variants: tamil, telugu, kannada, malayalam, marathi, gujarati, punjabi, bengali, oriya, hindi)

### Cluster 4: Time-zone / scheduling pain
template: `puja muhurat for {country} time zone | {city} pandit online`
- puja muhurat for usa eastern time
- puja muhurat for california pst
- (10 variants across time zones)

### Cluster 5: Diaspora-specific concerns
template: `{question} for NRI Hindu families`
- which puja before buying house in usa
- how to do shradh from abroad
- (10 long-tail question-based queries)

## TDD — content-first

before writing MDX, write expected test in `apps/web/tests/content/nri-puja-guides.test.ts`:

```typescript
import { describe, test, expect } from 'vitest';
import { readFileSync, readdirSync } from 'fs';
import { join } from 'path';

describe('NRI puja guide MDX', () => {
  const dir = 'apps/web/content/puja-guides/nri';
  const files = readdirSync(dir).filter(f => f.endsWith('.mdx'));

  test('has 3 hero pages', () => {
    expect(files.length).toBeGreaterThanOrEqual(3);
  });

  files.forEach(file => {
    const content = readFileSync(join(dir, file), 'utf-8');
    test(`${file} has frontmatter with required fields`, () => {
      expect(content).toMatch(/^---\n[\s\S]*?title:[\s\S]*?slug:[\s\S]*?primaryKeyword:[\s\S]*?country:[\s\S]*?---/);
    });
    test(`${file} ≥1200 words`, () => {
      const body = content.replace(/^---[\s\S]*?---/, '');
      expect(body.split(/\s+/).length).toBeGreaterThanOrEqual(1200);
    });
    test(`${file} has FAQ schema`, () => {
      expect(content).toMatch(/FAQPage/);
    });
    test(`${file} has USD or country-currency price`, () => {
      expect(content).toMatch(/\$|USD|CAD|GBP/);
    });
    test(`${file} has ≥3 internal links`, () => {
      const internalLinks = content.match(/\]\(\/[^)]+\)/g) || [];
      expect(internalLinks.length).toBeGreaterThanOrEqual(3);
    });
  });
});
```
