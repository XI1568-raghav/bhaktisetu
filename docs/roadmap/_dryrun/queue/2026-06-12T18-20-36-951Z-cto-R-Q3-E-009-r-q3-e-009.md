# R-Q3-E-009 — Affiliate tracking v1

caveman brief: build link tracker. UTM in → cookie → signup attribution → payout report. no fancy MLM. one-tier only.

## scope freeze (concretize thin spec)

success_criteria (locked, supersedes placeholder):

1. `affiliates` table in prisma/schema.prisma — fields: id, userId (FK), code (unique, 8-char slug), createdAt, payoutRate (decimal default 0.10), status enum(active|suspended)
2. `affiliate_clicks` table — id, code, utmSource, utmMedium, utmCampaign, ipHash, ua, referrer, landedPath, createdAt, sessionCookieId
3. `affiliate_conversions` table — id, affiliateId, userId (FK signup), orderId nullable, amountInr, commissionInr, status enum(pending|approved|paid), createdAt
4. middleware in apps/web/middleware.ts captures `?ref=<code>` OR `?utm_source=<code>` → sets `bs_aff` cookie 30-day
5. signup handler in apps/api/src/routes/auth.ts reads cookie → creates `affiliate_conversions` row with amountInr=0 status=pending
6. order webhook in apps/api/src/routes/payments/razorpay-webhook.ts → if user has affiliate row in last 30d → insert conversion with commission
7. payout report endpoint `GET /api/admin/affiliates/payouts?month=YYYY-MM` — auth required (admin role)
8. PostHog event `affiliate_signup` + `affiliate_conversion` emitted
9. KPI query populated: `SELECT COUNT(DISTINCT userId) FROM affiliate_conversions WHERE createdAt >= '2026-07-01'`
