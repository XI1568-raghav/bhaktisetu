# Q-R-Q2-M-011 — Referral program v1 (₹100 credit per converted referee)

## Context
Caveman briefing: ship /refer page + claim API + ledger. Inviter gets ₹100 wallet credit when invitee completes first paid booking. Idempotent. KPI flip referral_active=1.

## Scope (5 deliverables)

### 1. Prisma migration
File: `apps/api/prisma/schema.prisma` — append model:

```prisma
model Referral {
  id          String   @id @default(cuid())
  inviterId   String   @map("inviter_id")
  inviteeId   String   @unique @map("invitee_id") // idempotent: one claim per invitee
  status      ReferralStatus @default(pending)
  bookingId   String?  @map("booking_id")
  creditInr   Int      @default(0) @map("credit_inr")
  createdAt   DateTime @default(now()) @map("created_at")
  claimedAt   DateTime? @map("claimed_at")

  inviter     User     @relation("ReferralInviter", fields: [inviterId], references: [id])
  invitee     User     @relation("ReferralInvitee", fields: [inviteeId], references: [id])
  booking     Booking? @relation(fields: [bookingId], references: [id])

  @@index([inviterId, status])
  @@map("referrals")
}

enum ReferralStatus {
  pending
  claimed
}
```

Also add to User model: `referralCode String @unique @default(cuid()) @map("referral_code")` and back-relations `ReferralInviter`, `ReferralInvitee`.

Migration: `pnpm --filter @poojly/api exec prisma migrate dev --name add_referrals`

### 2. API routes
File: `apps/api/src/routes/referrals.ts` (new)

Endpoints:
- `GET /api/v1/referrals/me` → auth required → return `{ code, pendingCount, claimedCount, creditsEarnedInr }`
- `POST /api/v1/referrals/claim` → body `{ refCode, bookingId }` → auth required (invitee). Validates: (a) refCode resolves to user ≠ self, (b) booking exists, status=paid, owned by invitee, (c) no prior Referral row for inviteeId. Creates row status=claimed, credits inviter wallet +10000 paise via existing wallet service. Returns `{ ok, creditedInr: 100 }`. Idempotent: unique invitee_id constraint → catch P2002 → return existing row 200.

Wire in `apps/api/src/server.ts` route registry.

### 3. Checkout hook

After payment confirmed, if `req.cookies.ref` present, call internal `referrals.claim()` with that code. Wrap in try/catch — claim failure must NOT fail booking.
