## Translation guidance (founder-action item — see below)

Each macro must:
- Preserve every `{var}` placeholder verbatim (e.g., `{amount}`, `{temple_name}`).
- Use formal register (आप / நீங்கள் / మీరు / आपण / আপনি) — devotee context.
- Avoid colloquial Hinglish in hi.json (use shuddh Hindi for receipts, conversational Hindi for greetings).
- Tamil: use Tamil script, not romanized. Same for all.
- Use deity/temple-respectful terms (श्री, ஸ்ரீ, శ్రీ, श्री, শ্রী) where macro mentions deity name.
- Currency formatting: ₹{amount} stays universal across all langs.

## Fallback chain (in i18n/index.json)

```
hi → en
ta → en
te → en
mr → hi → en
bn → en
```

Marathi falls back to Hindi first (script + vocabulary overlap), then EN. Others go direct to EN.
