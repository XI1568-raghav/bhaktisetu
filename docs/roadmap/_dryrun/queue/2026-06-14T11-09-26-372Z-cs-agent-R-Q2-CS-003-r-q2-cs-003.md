# R-Q2-CS-003 — Multilingual CS Macros (Ta/Te/Bn/Mr)

## Why
p50 CS first-response time inflates for non-Hindi/English tickets — Tamil/Telugu/Bengali/Marathi users wait 4-8h vs ~45min for Hindi. 40 pre-translated macros covering top ticket intents shrinks agent response to <10min for these languages.

## Lever
**Reduce p50 CS response time for regional-language tickets from ~4h to <15min.**

Secondary: lift NPS for regional cohort (currently ~32, target +10).

## Deliverables

### 1. Macro source-of-truth file
Create: `docs/agent-reports/cs/macros/multilingual-macros-v1.yaml`

Schema:
```yaml
version: 1
generated_at: <ISO>
languages: [en, hi, ta, te, bn, mr]
macros:
  - id: M001
    intent: payment_failed_retry
    category: billing
    variables: [user_name, amount, order_id]
    translations:
      en: "Hi {user_name}, your payment of ₹{amount} for order {order_id}..."
      hi: "..."
      ta: "..."
      te: "..."
      bn: "..."
      mr: "..."
```

## Translation Quality Guardrails

- Use formal register for billing/legal (Tamil: `தாங்கள்` not `நீ`; Bengali: `আপনি` not `তুমি`; Marathi: `आपण` not `तू`; Telugu: `మీరు` not `నువ్వు`)
- Preserve brand name "Bhaktisetu" in Latin script across all langs
- Currency: `₹` symbol universal, no transliteration
- Time/date: ISO format in variable, render layer localizes
- **Founder action**: have one native speaker per language sanity-check before pasting into Wati. Flag in DEPLOY-RUNBOOK.md.
