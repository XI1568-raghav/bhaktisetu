# Q-C-20260614T0507-R-Q2-E-005 — Webhook idempotency (Razorpay + Stripe)

## Caveman context
Payment webhooks retry. Without idempotency key check → double credit, double email, double karma. Bad.
Solution: `idempotency_keys` table + middleware. Reject duplicates with cached response.

## TDD first

   - Assert: second → 200, side effects NOT re-executed (count unchanged)
   - Assert: response body identical (cached)

### Migration
**`packages/db/prisma/migrations/<timestamp>_idempotency_keys/migration.sql`** (new)
```sql
CREATE TABLE idempotency_keys (
  key TEXT PRIMARY KEY,
  provider TEXT NOT NULL CHECK (provider IN ('razorpay', 'stripe')),
  request_hash TEXT NOT NULL,
  response_status INT NOT NULL,
  response_body JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  expires_at TIMESTAMPTZ NOT NULL DEFAULT (now() + interval '7 days')
);
CREATE INDEX idx_idempotency_keys_expires ON idempotency_keys(expires_at);
CREATE INDEX idx_idempotency_keys_provider ON idempotency_keys(provider, created_at DESC);
```

Update `packages/db/prisma/schema.prisma`:
```prisma
model IdempotencyKey {
  key            String   @id
  provider       String
  requestHash    String   @map("request_hash")
  responseStatus Int      @map("response_status")
  responseBody   Json     @map("response_body")
  createdAt      DateTime @default(now()) @map("created_at")
  expiresAt      DateTime @default(dbgenerated("(now() + interval '7 days')")) @map("expires_at")
  @@index([expiresAt])
  @@index([provider, createdAt])
  @@map("idempotency_keys")
}
```

### Middleware
**`apps/api/src/middleware/webhook-idempotency.ts`** (new)
- Fastify preHandler hook
- Extract key: Razorpay → `x-razorpay-event-id` header OR `payload.payload.payment.entity.id`; Stripe → `stripe-event.id` after sig verify
- SHA256 of request body → `request_hash`
- `SELECT ... FOR UPDATE` on key:
  - exists + hash match → reply cached `response_body` with status, skip handler
  - exists + hash mismatch → 409 Conflict (log security alert)
  - not exists → INSERT placeholder row, let handler run, UPDATE with response on reply
- Use Prisma `$transaction` with SERIALIZABLE isolation for race safety
- Wrap reply.send to capture body before flush
