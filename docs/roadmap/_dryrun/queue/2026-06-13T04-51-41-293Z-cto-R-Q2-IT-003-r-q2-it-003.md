# R-Q2-IT-003 — Supabase backup automation

caveman brief: dump DB daily. push to object store. keep 30 days. rotate old.

## Pre-flight
1. Confirm Supabase project ID + DB connection string location (`SUPABASE_DB_URL` in env).
2. Check existing CI: `.github/workflows/` — see if scheduled workflow pattern exists.
3. Confirm vendor: default Supabase Storage (no new external dep). Founder may override post-PR.

## Implementation

1. **Backup script** — `scripts/backup/supabase-backup.ts`:
   - run `pg_dump $SUPABASE_DB_URL --format=custom --no-owner --no-privileges -f /tmp/backup.dump`
   - compute SHA256, log size
   - upload via Supabase Storage client (`@supabase/supabase-js`) OR S3 SDK if R2/B2 chosen
   - key: `backups/YYYY/MM/DD/bhaktisetu-<ISO>.dump`
   - log to console JSON-structured (for GH Actions parse)

2. **Retention script** — `scripts/backup/prune-old-backups.ts`:
   - list bucket objects with prefix `backups/`
   - delete any with `created_at < now - 30 days`

3. **GH Actions workflow** — `.github/workflows/db-backup.yml`:
   ```yaml
   on:
     schedule:
       - cron: '0 19 * * *'  # 00:30 IST daily
     workflow_dispatch:
   jobs:
     backup:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - run: sudo apt-get install -y postgresql-client-15
         - uses: pnpm/action-setup@v3
         - run: pnpm install --frozen-lockfile
         - run: pnpm tsx scripts/backup/supabase-backup.ts
           env:
             SUPABASE_DB_URL: ${{ secrets.SUPABASE_DB_URL }}
             SUPABASE_SERVICE_ROLE_KEY: ${{ secrets.SUPABASE_SERVICE_ROLE_KEY }}
             SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
         - run: pnpm tsx scripts/backup/prune-old-backups.ts
   ```

4. **Restore doc** — `docs/runbooks/db-restore.md`: step-by-step `pg_restore` from backup. Founder must be able to follow blind.

5. **Monitoring** — backup script must POST to `process.env.HEARTBEAT_URL` on success (cron healthcheck). If founder uses healthchecks.io free tier already in stack, wire it. Else log-only and add TODO.
