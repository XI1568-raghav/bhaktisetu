## Implementation

1. **Slow query logger** — `apps/api/src/db/slow-query-log.ts`:
   - Wrap ORM query executor. Threshold via `SLOW_QUERY_MS` env (default 100).
   - Emit to pino logger at `warn` level with structured fields.
   - If Drizzle: use `drizzle({ logger: { logQuery } })`. If Prisma: `$on('query')`.

2. **N+1 detector** — `apps/api/src/db/n-plus-one-detector.ts`:
   - AsyncLocalStorage to scope per-request.
   - Normalize SQL (strip params), count occurrences. Flag >5 of same template.
   - Log at end of request via Fastify `onResponse` hook.

3. **Wire into server** — register both in main Fastify bootstrap (cite file from pre-flight).

4. **Audit + fix N+1s** — run dev server, hit top 10 routes (list in PR description). Fix each via:
   - `eager loading` / `with: { relation: true }` for Drizzle
   - `include` for Prisma
   - batch via `inArray()` where loop-fetching detected
   Document each fix in `docs/perf/n-plus-one-fixes-Q2.md` with before/after query count.
