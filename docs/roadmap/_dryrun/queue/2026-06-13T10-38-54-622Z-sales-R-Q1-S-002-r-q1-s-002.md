## Deliverable
Single file: `docs/sales/playbooks/pandit-onboarding.md`

Required sections:

1. **Funnel overview** — diagram (markdown ascii) of stages: Intro → KYC → Profile → Contract → Test puja → Active. Expected drop-off % per stage and total intro→active target (≥ 60%).
2. **KYC checklist** — every document required:
   - Aadhaar (front + back) — verification flag in DB: `aadhaar_verified`
   - PAN — for payouts > ₹20k/yr
   - Bank account proof (cancelled cheque or passbook page)
   - Self photo (for profile)
   - Optional: GST if registered
   Cross-reference exact field names from `apps/api/src/routes/priest-onboarding.ts` (cite line numbers).
3. **Contract template reference** — link to `{CONTRACT_TEMPLATE_PATH}`. Key clauses founder must explain verbally: revenue share %, payout schedule, code of conduct, dispute resolution, termination. Bilingual summary (Hindi + English) of each clause in 1 sentence.
4. **Profile setup walkthrough** — step-by-step, screenshot placeholders `{SCREENSHOT_N}`:
   - Step 1: Phone OTP signup
   - Step 2: Aadhaar upload + verification
   - Step 3: Add expertise (Vedic puja types — list top 10: Satyanarayan, Griha Pravesh, Rudrabhishek, etc.)
   - Step 4: Set availability (calendar)
   - Step 5: Set base pricing per puja type
   - Step 6: Add photo + bio (provide bilingual bio template, 50-word)
   - Step 7: Bank details
   - Step 8: Submit for review
5. **Payout schedule** — exact terms:
   - Frequency: weekly (every Monday, prior week Mon-Sun)
   - Minimum payout: ₹500
   - Hold period for new pandits: first ₹2000 held until 3rd successful puja (anti-fraud)
   - Method: NEFT/IMPS to verified bank account
   - Statement: WhatsApp PDF
   - Cite source-of-truth file/setting if exists in repo; else mark `{PAYOUT_CONFIG_TBD}` and flag for founder.
6. **First-puja success protocol** — founder/CMO handholds first puja: pre-call 24h before, post-puja review collection within 2h. Why: drives ≥4.5/5 rating success criterion.
7. **Bilingual onboarding script** — what founder says during the 20-minute onboarding call (Hindi primary, English fallback). Include greeting, doc collection sequence, expectation setting (payout timing, review system, no-show penalties).
8. **Common onboarding blockers + fixes** — 5 items: Aadhaar photo blurry, bank account in family member's name, no smartphone, low literacy, hesitation about commission %.
9. **Onboarding tracker template** — markdown table: pandit_name, city, intro_date, kyc_complete_date, profile_live_date, first_puja_date, current_status, rating, notes.
10. **Weekly review cadence** — every Sunday: count signups vs 5/week target, churn check (any pandit with 0 pujas in 14d post-onboarding), rating review.
