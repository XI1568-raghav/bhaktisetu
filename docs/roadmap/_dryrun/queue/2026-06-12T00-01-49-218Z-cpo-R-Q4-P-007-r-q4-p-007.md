### 2. Pricing Tiers
- **Early-bird** (T-60 to T-30 days): -15% off base
- **Regular** (T-30 to T-0): base price
- **Waitlist conversion** (sold out → seat freed): base +10% (scarcity premium)
- Worked example per festival with rupee figures

### 3. UX Flows + Wireframes

#### 3.1 Calendar Discovery `/festivals`
- Grid of festival cards (image, name, date, days-until countdown, "from ₹X early-bird")
- Filter: month / temple / festival type
- ASCII wireframe

#### 3.2 Festival Detail `/festivals/[slug]`
- Hero (festival name, date, pre-sale window remaining timer)
- Temple list (each with seats remaining + tier price)
- Tier selector showing % savings vs regular
- ASCII wireframe

#### 3.3 Waitlist Modal
- Triggered when "Sold out" on temple card
- Capture email + phone, deposit ₹100 refundable (commitment device)
- Show queue position, ETA
- ASCII wireframe

#### 3.4 Reminder System
- T-7d: email + WhatsApp ("Your Diwali puja in 7 days")
- T-1d: WhatsApp + SMS ("Tomorrow! Here's join link / venue details")
- T-0 morning: WhatsApp ("Puja begins at HH:MM — link/directions")
- Copy templates for each channel
