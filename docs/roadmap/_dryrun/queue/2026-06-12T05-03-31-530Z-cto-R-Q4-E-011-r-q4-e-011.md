## Schema spec (Prisma)

```prisma
model FestivalPresale {
  id                String   @id @default(cuid())
  festivalSlug      String   @unique @map("festival_slug")
  displayName       String   @map("display_name")
  pujaTypeId        String?  @map("puja_type_id")
  festivalDate      DateTime @map("festival_date") @db.Date
  presaleStartAt    DateTime @map("presale_start_at")
  presaleEndAt      DateTime @map("presale_end_at")
  earlyBirdPct      Int      @default(0) @map("early_bird_pct")
  capacity          Int?
  waitlistEnabled   Boolean  @default(true) @map("waitlist_enabled")
  heroBlurb         String?  @map("hero_blurb")
  createdAt         DateTime @default(now()) @map("created_at")
  pujaType          PujaType? @relation(fields: [pujaTypeId], references: [id])
  waitlist          FestivalPresaleWaitlist[]
  @@map("festival_presale")
}

model FestivalPresaleWaitlist {
  id            String   @id @default(cuid())
  userId        String   @map("user_id")
  festivalSlug  String   @map("festival_slug")
  email         String
  phone         String?
  createdAt     DateTime @default(now()) @map("created_at")
  festival      FestivalPresale @relation(fields: [festivalSlug], references: [festivalSlug])
  @@unique([userId, festivalSlug])
  @@index([festivalSlug])
  @@map("festival_presale_waitlist")
}
```

## API contracts

**GET /api/v1/festivals/upcoming**
```json
{
  "festivals": [
    {
      "slug": "guru-purnima-2026",
      "displayName": "Guru Purnima",
      "festivalDate": "2026-07-21",
      "presaleStartAt": "2026-05-22T00:00:00Z",
      "presaleEndAt": "2026-07-20T23:59:59Z",
      "presaleActive": true,
      "daysUntil": 39,
      "waitlistEnabled": true,
      "earlyBirdPct": 15
    }
  ]
}
```
Filter: `festivalDate <= now + 90d AND festivalDate >= now`.
Public, no auth, cache 5min (`Cache-Control: public, max-age=300`).

**POST /api/v1/festivals/:slug/waitlist**
- Auth required (existing middleware in apps/api).
- Body: `{ email: string, phone?: string }`.
- Idempotent: upsert on `(userId, festivalSlug)`. Return 200 with `{ status: 'queued' | 'already_queued', waitlistId }`.
- 404 if festival slug not found.
