## Schema (Prisma)

```prisma
model Affiliate {
  id                String   @id @default(cuid())
  userId            String   @unique
  user              User     @relation(fields: [userId], references: [id])
  code              String   @unique  // short, URL-safe, e.g. "rahul7k2"
  clicks            Int      @default(0)
  signups           Int      @default(0)
  paidConversions   Int      @default(0)
  payoutInr         Int      @default(0)  // paise or rupees — pick paise for precision
  createdAt         DateTime @default(now())
  events            AffiliateEvent[]
  @@index([code])
}

model AffiliateEvent {
  id           String   @id @default(cuid())
  affiliateId  String
  affiliate    Affiliate @relation(fields: [affiliateId], references: [id])
  type         String   // "click" | "signup" | "paid_conversion"
  referredUserId String?
  bookingId    String?
  amountInr    Int?     // paise, for paid_conversion only
  createdAt    DateTime @default(now())
  @@index([affiliateId, type, createdAt])
}
```

## UTM + referral capture flow

1. User visits `bhaktisetu.com/refer/rahul7k2`:
   - Server-side: increment `Affiliate.clicks`, create `AffiliateEvent{type:"click"}`
   - Set cookie `bs_ref=rahul7k2; Max-Age=2592000; Path=/; SameSite=Lax`
   - 302 → `/`
2. User browses, eventually signs up:
   - Signup handler reads `bs_ref` cookie → calls `attributeSignup(newUserId, code)`
3. User makes first paid booking:
   - Payment success handler checks if user has affiliate attribution + no prior paid_conversion → calls `attributePaidConversion(userId, bookingId, amountInr)`
4. PostHog: on every page load, if `?ref=` or `utm_source=` present, call `posthog.register({referral_code, utm_source, utm_campaign})` to attach as super properties
