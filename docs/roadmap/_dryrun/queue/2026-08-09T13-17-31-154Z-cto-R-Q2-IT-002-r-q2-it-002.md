### Shell-safety rules (CRITICAL — /bin/sh bug in queue)

- NEVER use `grep "foo (bar)"` — unescaped parens trigger `Syntax error: ( unexpected`
- Use `grep -q` (exit code only, no stdout noise)
- Use `grep -i` for case-insensitive matches where wording varies
- If pattern itself contains parens, switch to `fgrep "literal text"` — `fgrep` treats pattern as fixed string
- Script MUST exit 0 and print exactly one integer (`1` or `0`) to stdout — nothing else
- Test with `sh scripts/metrics/render_scale_plan_documented.sh` not `bash` (Render cron uses /bin/sh)
