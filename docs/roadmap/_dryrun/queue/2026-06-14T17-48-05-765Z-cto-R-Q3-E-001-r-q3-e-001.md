## Implementation

### `apps/api/src/lib/pii-redactor.ts` (NEW)
- Pure fn `redactPII(text: string): string`
- Regex: `/(\+?91[-\s]?)?[6-9]\d{9}/g` → `[REDACTED_PHONE]`
- Email: standard RFC → `[REDACTED_EMAIL]`
- Aadhaar: `/\b\d{4}\s?\d{4}\s?\d{4}\b/g` → `[REDACTED_ID]`
- PAN: `/\b[A-Z]{5}\d{4}[A-Z]\b/g` → `[REDACTED_ID]`

### `apps/api/src/lib/groq-client.ts` (NEW)
- `transcribeAudio(buffer: Buffer, mimeType: string)` → POST `https://api.groq.com/openai/v1/audio/transcriptions` model `whisper-large-v3-turbo`
- `chatCompletion(messages)` → model `llama-3.3-70b-versatile`, system prompt at `apps/api/src/prompts/pandit-system.md` (create with bhakti tone, Sanskrit-aware, devotional)
- Throw `VoicePipelineError('stt' | 'chat', upstreamStatus)` on non-200. NO RETRY WITH FAKE DATA.

### `apps/api/src/lib/elevenlabs-client.ts` (NEW)
- `synthesizeSpeech(text)` → POST `https://api.elevenlabs.io/v1/text-to-speech/{voiceId}/stream` model `eleven_turbo_v2_5`, returns audio stream
- Throw `VoicePipelineError('tts', status)` on failure

### `apps/api/src/routes/voice-pandit.ts` (NEW)
- Three sub-routes: `/stt`, `/chat`, `/tts` (separated so frontend can stream + show progress)
- Each route: validate env keys → call client → emit `voice_pandit_leg_completed` telemetry with leg + durationMs
- On `VoicePipelineError` → return 503 `{ error: 'voice_pipeline_unavailable', leg, upstreamStatus }`
- Register in `apps/api/src/index.ts` (or wherever routes wired — grep `ask-pandit` import)

### `apps/web/components/VoicePanditWidget.tsx` (NEW)
- MediaRecorder API, push-to-talk button
- onStop → POST `/api/voice-pandit/stt` → POST `/api/voice-pandit/chat` → POST `/api/voice-pandit/tts` → play audio
- Track `roundTripMs` total + per-leg
- Emit `voice_pandit_session_started` (on mic press) + `voice_pandit_session_completed` (on audio play) PostHog events with `{ roundTripMs, sttMs, chatMs, ttsMs, transcriptLength, replyLength }`
- Post-session 5-star rating UI → emit `voice_pandit_session_rated` event
- ANY error → red banner, no fallback to text endpoint

### `apps/web/app/ask-pandit/page.tsx` (EDIT)
