## JSON Schema (Zod)
```ts
z.object({
  id: z.string().regex(/^cs-macro-[a-z0-9-]+$/),
  title: z.string().min(3).max(80),
  triggerKeywords: z.array(z.string()).min(1),
  category: z.enum(['booking','payment','pandit','delivery','compliance','account','pricing']),
  responseBody: z.string().max(800), // ~120 words
  escalationCriteria: z.string().min(10),
  relatedRunbook: z.string(),
})
```

## API Endpoints
- `GET /admin/cs-macros` — list all
- `GET /admin/cs-macros?category=payment` — filter by category
- `GET /admin/cs-macros?q=refund` — search title + triggerKeywords + responseBody (case-insensitive substring)
- `GET /admin/cs-macros/:id` — single macro, 404 if missing

Auth: reuse existing admin middleware. If none exists → gate with `x-admin-token` header check against `process.env.ADMIN_TOKEN` and add TODO comment linking to auth roadmap item.
