## Deliverables

### 1. Target List
`docs/agent-reports/sales/R-Q3-S-001-target-list.csv`

Columns: `name, phone, email, temple_or_org, locality_chennai, languages_spoken, specialty_pujas, source_url, source_date, confidence_high_med_low, notes`

Sources to mine (in order):
1. Major Chennai temple official sites (Kapaleeshwarar, Parthasarathy, Marundeeswarar, Vadapalani Murugan, Ashtalakshmi) — staff/priest contact pages
2. Justdial / Sulekha listings for "pandit Chennai" with phone visible
3. Archived south-india purohit directories (web.archive.org if live link dead)
4. Tamil Nadu HR&CE department public priest registers if accessible online
5. LinkedIn for purohits who self-list

Quality bar: Skip entry if phone not verifiable from at least one public source.

### 2. Scripts
`docs/agent-reports/sales/R-Q3-S-001-script-en.md`
`docs/agent-reports/sales/R-Q3-S-001-script-ta.md` (Tamil)

Structure both:
- Opener (5 sec — name, "Bhaktisetu se baat kar raha hoon" equivalent)
- Value prop (20 sec — what they get, no fluff)
- Ask (10 sec — 10-min onboarding call, no commitment)
- Close (5 sec — best time tomorrow)

Tone: respectful, addresses as "Swamigal" / "Sastrigal" appropriately. Note honorific in script header.

**Caveat:** Agent likely not native Tamil. Mark Tamil script `DRAFT — needs native review` and list 2-3 questionable phrases for founder/native speaker to fix.

### 3. Objection Handler
`docs/agent-reports/sales/R-Q3-S-001-objections.md`

Cover minimum:
- "I already have enough clients" → scarcity/extra-income angle
- "What is the commission?" → transparent number, framing
- "Is this verified/legitimate?" → trust signals, refer to existing onboarded pandits in BLR/Mumbai
- "I don't use apps" → WhatsApp-first onboarding promise
- "Send me details on WhatsApp first" → script for what to send + follow-up cadence

Each: 2-line rebuttal, EN + Tamil.
