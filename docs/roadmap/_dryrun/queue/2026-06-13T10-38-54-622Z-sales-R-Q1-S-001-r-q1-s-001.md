# Q-R-Q1-S-001 — Temple Outreach Script v2 (Varanasi)

## Goal
Produce `docs/sales/playbooks/temple-outreach.md` — a complete, battle-tested cold outreach script the founder will use to call/WhatsApp 20 temples per day in Varanasi to source 50 verified pandits.

## Context (read before writing)

- `docs/company/05-sales.md` — sales doctrine, objection patterns
- `apps/api/src/routes/priest-onboarding.ts` — current onboarding flow (so script promises match reality)

- Parent KPI: 50 verified pandits in Varanasi by month 2; current 8

## Deliverable
Single file: `docs/sales/playbooks/temple-outreach.md`

Required sections (in order):

1. **Purpose & Target** — one-paragraph: who calls who, expected outcome per call (referral to ≥1 pandit), success rate target (founder books 5 pandit intros per 20 calls = 25%).
2. **Pre-call checklist** — temple name, mahant/priest-in-charge name, deity, peak puja days, prior context if any.
3. **Hindi phone script** — Devanagari script, ~90 seconds spoken. Opening (10s namaste + identify), value prop (30s: free listing + booking revenue share, no upfront cost), ask (20s: intro to 1–2 pandits at temple), close (10s WhatsApp follow-up confirm). Include verbatim pauses [PAUSE], tone cues [SOFT], regional honorifics (Panditji, Maharaj-ji).
4. **English phone script** — same structure, for English-comfortable temple admins (younger generation, urban temples).
5. **Hindi WhatsApp variant** — text-only, 4–6 lines, Devanagari, includes 1 link placeholder `{onboarding_link}`. Must work when read silently. Include emoji sparingly (🙏 only).
6. **English WhatsApp variant** — same constraints.
7. **Value prop matrix** — table with 3 rows: (a) free listing — temple gets discovery, (b) booking revenue share — explicit % (cite contract — leave `{REV_SHARE_PCT}` placeholder, founder fills), (c) verified-pandit badge — trust signal for devotees.
8. **Objection handlers (exactly 3)** — each with: objection verbatim (Hindi + English), root concern, 2-sentence rebuttal (Hindi + English), escalation path if rebuttal fails.
   - O1: "Hum already manually book karte hain, app ki zaroorat nahi" (we already book manually)
   - O2: "Commission kyon doon? Devotee sidha aata hai" (why pay commission, devotee comes directly)
   - O3: "Aadhaar verification mein time lagega, pandit ji ko pasand nahi" (KYC friction)
9. **Call-log template** — markdown table columns: date, temple, contact, language, outcome (intro/callback/no), pandits_referred, next_action, notes.
10. **Daily target & tripwire** — 20 calls/day → 5 pandit intros/day → 25 verified/week (with 50% conversion intro→verified). If <10 intros/week after 2 weeks, escalate to founder for pivot review (tripwire on parent item: `verified_pandits_count_varanasi < 15 by 2026-08-01`).
