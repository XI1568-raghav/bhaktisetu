## Implementation notes

- **Model**: `llama-3.3-70b-versatile` (Groq free tier)
- **Streaming**: use Groq SDK `stream: true`, return `text/event-stream`
- **Rate limit store**: in-memory Map keyed by `ip:YYYY-MM-DD` and `userId:YYYY-MM-DD`. Upgrade to Redis is follow-up.
- **System prompt** must enforce: respond in user's `language` (hi/sa/en), cite Gita chapter.verse or Upanishad name when quoting, refuse non-dharmic questions politely
- **PostHog event**: emit `ai_pandit_response_emitted` with `{distinct_id, language, question_length, response_length, latency_ms}` AFTER successful stream completion
