## prisma schema additions

```prisma
model Wedding {
  id           String   @id @default(cuid())
  userId       String
  user         User     @relation(fields: [userId], references: [id])
  muhuratDate  DateTime
  city         String
  budgetInr    Int
  status       WeddingStatus @default(draft)
  totalInr     Int      @default(0)
  razorpayOrderId String? @unique
  vendors      WeddingVendor[]
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt
  @@index([userId, status])
}

model WeddingVendor {
  id          String   @id @default(cuid())
  weddingId   String
  wedding     Wedding  @relation(fields: [weddingId], references: [id], onDelete: Cascade)
  vendorType  VendorType  // pandit | venue | catering | photographer | muhurat_advisor
  vendorId    String       // FK to existing vendor table (varies by type)
  priceInr    Int
  status      VendorBookingStatus @default(pending)
  notes       String?
  @@unique([weddingId, vendorType])
}

enum WeddingStatus { draft inquiry booked paid completed cancelled }
enum VendorType { muhurat_advisor pandit venue catering photographer }
enum VendorBookingStatus { pending confirmed cancelled }
```

## the hard part: atomic 5-vendor transaction

`apps/api/src/services/wedding-booking-tx.ts`:

```ts
// pseudo — implement with prisma.$transaction
async function bookWedding(weddingId, vendorSelections) {
  return prisma.$transaction(async (tx) => {
    // 1. re-check availability for ALL 5 vendors (race condition guard)
    // 2. lock each vendor's slot row (SELECT FOR UPDATE)
    // 3. insert 5 WeddingVendor rows
    // 4. compute total
    // 5. create razorpay order (idempotency key = weddingId)
    // 6. update Wedding.status = inquiry, totalInr, razorpayOrderId
    // any throw → rollback all
  }, { isolationLevel: 'Serializable', timeout: 15000 });
}
```

razorpay webhook handler (existing file apps/api/src/routes/payments/razorpay-webhook.ts):
- on payment.captured for wedding order → set Wedding.status=paid, all WeddingVendor.status=confirmed
- emit posthog `wedding_booked` event
- IF E-009 merged → call `emitAffiliateConversion(userId, totalInr, weddingId)`
