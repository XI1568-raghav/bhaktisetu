### 4. KPI query
File: `apps/api/src/routes/cs-sla-kpi.ts` (GET `/cs/sla/kpi`)
```sql
SELECT
  COUNT(*) FILTER (WHERE first_response_at_utc IS NOT NULL
                   AND first_response_at_utc <= created_at_utc + interval '24 hours')::float
  / NULLIF(COUNT(*), 0) * 100 AS response_sla_24h_pct,
  COUNT(*) AS total_tickets,
  COUNT(*) FILTER (WHERE sla_breached) AS breached_count
FROM cs_tickets
WHERE created_at_utc >= now() - interval '30 days';
```
Auth: service-role bearer only. Test in `__tests__/cs-sla-kpi.test.ts`.
