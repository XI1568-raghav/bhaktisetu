## Implementation

### Step 1: jscodeshift transform
Create `codemods/json-ld-nonce.ts`:
- Match JSX opening elements where name === `script` AND has attribute `type` with value `application/ld+json`
- Add attribute `nonce={nonce}` (JSX expression container)
- Inject nonce source at top of component body (if not already present):
  ```ts
  import { headers } from 'next/headers';
  // in async server component:
  const nonce = (await headers()).get('x-csp-nonce') ?? '';
  ```
- If component is NOT async / already has nonce var, reuse — do not redeclare
- Idempotent: skip if `nonce` attr already on element
- Skip client components (`"use client"`) — nonces only work server-side; log to console for manual review

### Step 2: dry-run codemod
```
pnpm exec jscodeshift -t codemods/json-ld-nonce.ts apps/web/app --extensions=tsx,ts --dry --print 2>&1 | tee codemods/json-ld-nonce.dryrun.log
```
Review log. Confirm JSON-LD blocks matched, non-JSON-LD scripts untouched.

### Step 3: apply codemod
```
pnpm exec jscodeshift -t codemods/json-ld-nonce.ts apps/web/app --extensions=tsx,ts
```

### Step 4: verify counts

echo "total=$TOTAL nonced=$NONCED"
