1. /antim-sanskar landing — dignified hero + 3-step explainer
2. Form: deceased name + family contact + location + tradition (Vedic/specific lineage) + budget preference
3. Bhaktisetu auto-matches available specialist pandit (per R-Q4-S-007)

6. Day-of: pandit + assistant attend, conduct rituals
7. Post-service: video proof (consent gated) + 80G receipt (if applicable to donation portion) + check-in call 7 days
