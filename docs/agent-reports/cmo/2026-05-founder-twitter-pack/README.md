## How founder uses it

1. Read each thread top-to-bottom. Rewrite freely in your voice — agent voice is a scaffold, not the final post.
2. Pick a scheduler (Typefully / Buffer) or post manually 3×/week (Mon-Wed-Fri 9am IST).
3. Reply to first comments within 2 hours during the first 4 hours of a thread's life.
4. Log weekly numbers in `metrics-tracker.md` every Sunday night.
5. After Week 4, review the metrics — if +250 followers/month not hitting, narrow audience focus to NRI (highest LTV).

## Security note

This pack contains **zero credentials**. Bhaktisetu agent has no Twitter API access. All posting is founder-side. Never request Twitter OAuth tokens, API keys, or session cookies from the agent — they are explicitly out of scope.
