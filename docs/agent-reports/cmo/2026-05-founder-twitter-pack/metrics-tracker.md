## How to pull each number

- **Followers (end):** X profile page, top right.
- **Δ followers:** end-of-week followers minus end-of-prior-week. First week = end W1 minus pre-cycle baseline.
- **Impressions (7d):** X analytics → 7-day window ending Sunday.
- **Profile clicks:** X analytics → "Profile visits."
- **Link clicks → bhaktisetu.com:** Plausible / GA / CF web analytics → filter referrer = `t.co` or `twitter.com` or `x.com`, count unique sessions for the week.
- **Best thread:** thread with the highest impressions that week (note the file slug, e.g. `W2-2`).
- **Notes:** anything notable — viral spike, mention from a larger account, paid amp test, festival overlap.

## Decision rules

- If **Δ followers W1 < 20:** reply window may be too short. Extend to 4h SLA + post a 4th thread that week as a recovery test.
- If **Δ followers W2 < 50:** narrow audience to NRI-only for W3-W4 (highest LTV — they convert into paid USD bookings, not just followers).
- If **Δ followers M5 < 100:** ratchet roadmap KPI to 250/month sustained (see `success-criteria-update.md`) and re-evaluate the channel.
- If **Δ followers M5 ≥ 250:** keep cadence + plan a Month 6 paid amp test (₹5,000 boost on the single best-performing thread).

## Annual targets context

- Q2 cumulative target (per roadmap): 1000 followers.

- Tripwire: if NRI conversion rate from Twitter ↓ bhaktisetu.com < 1% by W4, this channel is a brand play, not a growth lever — keep cadence but stop counting on it for paid conversion.
