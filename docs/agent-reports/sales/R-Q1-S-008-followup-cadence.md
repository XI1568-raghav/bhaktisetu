# Follow-up Cadence — Gaushala Onboarding (R-Q1-S-008)

D0/D2/D5/D10/D21 touchpoint plan per prospect. Channel + message stub + escalation rule.

## Channel-by-channel discipline

### WhatsApp
- Use WhatsApp Business if available (better delivery + read receipts)
- Send between 10am-7pm IST only (no evening/late-night)
- Never more than 2 messages without a reply (avoids spam-block)
- After 3 unanswered WAs: switch to email or phone

### Email
- Subject lines short, no caps, no exclamations
- Send Mon/Tue/Wed mornings (10am-12pm IST) - highest open rates for nonprofits
- Avoid Friday afternoon and weekend
- Attach 1-page brief only on D10 (not D0 - reduces D0 spam classification)

### Phone
- Call 10am-12pm or 4pm-6pm IST (avoid lunch, evening aarti times)
- Identify yourself + Bhaktisetu in first 5 seconds
- Ask "is this a good 90 seconds" - respect their time
- Always offer to call back at their convenience
- Never call back-to-back on the same day if no answer (1 retry max same day, gap 3-4h)

### LinkedIn (T1 prospects only)
- Use only if founder has personal LinkedIn presence active
- Connect request with 200-char personalized note
- Use ONLY for trustees with visible LinkedIn profiles
- Do not InMail spam - send 1 connect, wait 7 days, send follow-up note only if accepted

**Total founder time:** ~22 hours across 18 prospects, spread over 4 weeks.

## Reply-based exit (positive)

The moment a prospect replies positively:
1. Exit the chase cadence
2. Schedule the 30-min discovery call within 48h
3. Send Zoom/Meet link + agenda + 1-page brief 24h before call
4. After call: send within-24h thank-you + next steps + draft partnership agreement
5. Tag in CRM as "active onboarding"

## Reply-based exit (negative)

If prospect says NO:
1. Exit cadence immediately
2. Thank them sincerely - one paragraph max
3. Park in CRM "passed" bucket
4. Set 6-month calendar reminder for soft check-in (only if reason was timing, not fit)

## Escalation rules (warning signs to founder)

- Any prospect responds with hostility -> stop all outreach immediately, log reason
- Any prospect requests "no contact" -> add to permanent do-not-contact list
- Any prospect raises legal/regulatory question we can't answer -> escalate to legal advisor before responding
- If 0 positive responses by D10 across 8+ prospects -> review outreach quality before continuing D10/D21 touches on remaining prospects

## CRM minimum (founder-tracked spreadsheet OK for v1)

Columns to maintain per prospect:
- Name, tier, contact_name, phone, email, source_url
- D0 sent (date)
- D2 sent (date) + response status
- D5 call attempted (date) + outcome
- D10 sent (date) + response status
- D21 sent (date) + response status
- Current status: NEW / OUTREACH / ACTIVE / PASSED / PARKED
- Last touch date
- Next action date
- Notes (free text)

## Founder execution rhythm

Recommended:
- **Mon morning:** Send 4-5 D0 outreaches per week
- **Wed morning:** Send D2 WA nudges for prior Monday's batch
- **Fri morning:** Make D5 phone calls for 2 weeks ago batch
- **Following Mon:** D10 emails
- **Three weeks later Mon:** D21 final touches

This produces a steady funnel: 4-5 new D0 per week x 4 weeks = 16-20 prospects reached, expected 5-8 onboarding conversations, 5 closed.
