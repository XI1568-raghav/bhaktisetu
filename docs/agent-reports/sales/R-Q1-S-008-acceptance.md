# R-Q1-S-008 Acceptance Checklist

Pre-flight check before producing artifacts. Mark each before completion.

## Acceptance criteria

1. [x] CSV has >=15 prospects (3x target=5 for funnel headroom)
2. [x] CSV columns: name, city, state, contact_name, phone, email, website, source_url, sampradaya, cow_count_est, suggested_approach, priority_tier
3. [x] Each row has at least one verifiable source_url (gaushala website, Rajasthan Gau Seva Ayog, Bharatiya Gau Raksha Dal, news, registry)
4. [x] WA + email + call script delivered in EN and HI (Devanagari, not transliteration)
5. [x] Qualification rubric has scoring 1-5 on: legal status, transparency, cow welfare practice, digital readiness, geographic fit
6. [x] Follow-up cadence covers D0/D2/D5/D10/D21 touchpoints

## Scope guardrails

- NO fabricated phone numbers. Unverified -> blank + `needs-founder-research` note in row.
- NO new cities (Chennai/Pune/Kolkata gaushalas OUT OF SCOPE).
- NO actual outbound. Agent stops at artifact handoff.
- HI translations in proper Devanagari.
