## Call script

**Opening (60 sec):**

> "नमो गुरुभ्यः। मेरा नाम <founder> है, भक्तिसेतु की ओर से। क्या यह आचार्य महोदय के कार्यालय से बात करने का उपयुक्त समय है? यदि सन्ध्या या अनुष्ठान का समय हो तो कृपया मुझे पुनः समय सूचित कर दीजिए।"

**Value frame (90 sec):**

> "हम गृहस्थ दानदाताओं को सत्यापित गुरुकुलों से जोड़ते हैं। हमारे पास तीन निश्चित बिंदु हैं — एक, कोई पंजीकरण शुल्क नहीं। दो, दान-राशि पर कोई कमीशन नहीं। तीन, पूर्ण लेखा-जोखा संस्था को उपलब्ध। हम संस्था की 80जी पंजीकरण के अधीन ही दान स्वीकार करते हैं — कभी व्यक्तिगत खातों में नहीं।"

**Discovery (3–5 min):**

> 1. "वर्तमान ब्रह्मचारी संख्या क्या है? कौन-सी परम्परा का अनुसरण?"
> 2. "क्या संस्था पहले से online-दान स्वीकार कर रही है, या यह नूतन विषय है?"
> 3. "ब्रह्मचारियों की गोपनीयता संबंधी संस्था के नियम क्या हैं?"
> 4. "क्या sponsor-a-curriculum (जैसे एक वेद-शाखा का एक वर्ष का व्यय) के विषय में संस्था का दृष्टिकोण क्या है?"

**Close (60 sec):**

> "यदि सब उपयुक्त लगे, तो हम संस्था को एक संक्षिप्त लिखित प्रस्ताव भेज देंगे — आचार्य महोदय अपनी सुविधा से समीक्षा कर सकेंगे। कोई बाध्यता नहीं। क्या ईमेल हम <office email> पर भेजें, अथवा कोई अन्य पता उपयुक्त है?"

## Per-sampradaya variant notes

- **Gaudiya** (ISKCON Sandipani Muni, BGIS, Jiva, Vraja): use "Bhakti-shastri" / "Sandarbha" curriculum framing. Reference Bhaktivedanta Gurukulas directory in source line. NEVER bundle with Smarta or Madhva pitches.
- **Smarta-Advaita** (SSVV, Sandipani Pratishthan, Vipra Bharati): reference Rashtriya Sanskrit Sansthan affiliation. "Veda-shakha adhyayan" framing. Yajurveda / Rigveda / Samaveda recitation sponsorship resonates.
- **Madhva** (Poornaprajna Vidyapeetha): reference Udupi Ashta-Matha network. "Tarka / Mimamsa" curriculum framing. Do NOT use Gaudiya terms like "Bhakti-shastri" — Madhva sampradaya has its own canonical curriculum (Sarvamoola).
- **Advaita-Vedanta** (Chinmaya CIF, Arsha Vidya): "Vedanta-shravana" / "Upanishad-bhashya" framing. Sankara-bhashya curriculum. Reference Chinmaya International Foundation pathshala directory.
- **Arya-Samaji-Vedic** (Gurukul Kangri): "Yajna / arsha-path" framing. Do NOT use Puranic deity references — Arya Samaj rejects post-Vedic mythology.
