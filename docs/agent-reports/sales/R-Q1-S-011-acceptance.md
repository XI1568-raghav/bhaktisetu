# R-Q1-S-011 Acceptance Criteria

> Item: Onboard 10 store owners (prasad / brass / sacred texts)
> Cities locked: Varanasi, Bengaluru, Mumbai. No new cities.

## Acceptance bar

1. **CSV ≥25 prospects** (funnel ratio 2.5x to 10-store target) at `R-Q1-S-011-store-target-list.csv` with columns:
   `name,city,locality,category,contact_name,phone,gst_status,years_in_business,shipping_capable,source_url,priority_tier,fssai_status,notes`
2. **Distribution**: ≥8 prasad, ≥8 brass, ≥8 texts. ≥6 prospects per city.
3. **Outreach templates** at `R-Q1-S-011-outreach-templates.md`:
   - WhatsApp opener (category-specific value prop)
   - Email body with commission slab table
   - Walk-in pitch script (Hinglish + regional tags)
4. **Qualification rubric** at `R-Q1-S-011-qualification-rubric.md` scoring GST status, shipping/COD capable, inventory size, digital readiness, price competitiveness, hygiene (prasad only).
5. **Partner playbook** at `R-Q1-S-011-partner-playbook.md` covering commission structure scenarios, settlement cadence, returns policy, packaging SOP for prasad, FSSAI cold-chain guidance.
6. **Follow-up cadence** at `R-Q1-S-011-followup-cadence.md` with D0/D2/D5/D10/D20 touchpoints.
7. **Summary** at `R-Q1-S-011-summary.md` with top-10 dial list by city/category.
8. **Founder action required**: walk-ins, calls, commission finalization, FSSAI verification, hold-list cities.

## Out of scope

- New cities (Pune/Delhi/Ahmedabad → hold-list file if discovered).
- Promises on exact commission % (use 8-15% range).
- Brass items >5kg logistics (flag for separate logistics-partner roadmap).
- Walk-in execution (founder/field rep).
