# Influencer Outreach — 10 Micro-Influencers (5K-50K Devotional Niche)

> **Roadmap item**: R-Q2-M-005 (P1) · **Authored**: 2026-06-13

## Goal

Sign 10 micro-influencers in devotional niche (5K-50K followers) for Bhaktisetu collabs by Q2-end. Target combined 200K reach + ≥50 bookings attributed.

## Target shortlist (10)

| Niche | Profile type | Sample list |
|---|---|---|
| Vedic astrology IG | 5K-30K, daily horoscope reels | search "#vedicastrology" India top reach |
| Bhakti music YT | 10K-50K, devotional song | "bhajan singer" mid-tier |
| Hindi spiritual TT | 10K-50K, shloka explainers | TikTok ban India (skip) |
| Yatra travel IG | 5K-20K, char dham reels | Real travelers, not aggregators |
| NRI Hindu community | 5K-25K, IG/YT US-based | US/UK NRI |
| Festival cooker IG | 10K-50K, vrat recipes | Niche but high engagement |
| Daily verse podcast | YT/Spotify | Daily Gita teachers |

## Outreach playbook

1. **Identify**: Manual research week 1. Spreadsheet 50 candidates → shortlist 25 → outreach top 10
2. **Outreach DM**: Polite intro + brief + offer. Template in `docs/marketing/influencer-dm-template.md` (separate)
3. **Compensation tiers**:
   - Tier A (5-15K followers): ₹3K-5K/post + free puja for self/family
   - Tier B (15-30K): ₹8K-15K/post + 1 free yatra package
   - Tier C (30-50K): ₹20K-50K/post + 6-mo unlimited platform access
4. **Tracking**: Unique discount code per influencer (e.g. `BHAKTI-RAVI10`) attributing booking + 10% off
5. **Disclosure**: Mandate ASCI India influencer marketing guideline compliance (`#paidpartnership` tag)
