## Per-page SEO optimization checklist

For each pillar page:

- [ ] H1 contains target keyword (primary)
- [ ] H2-H3 contain related keywords + synonyms
- [ ] Meta description 150-160 chars w/ keyword
- [ ] URL slug includes keyword (hyphenated)
- [ ] First 100 words include keyword 1-2x naturally
- [ ] Internal links 3-5 to related pages
- [ ] External links 1-3 to authoritative sources
- [ ] Image alt text descriptive (no keyword stuffing)
- [ ] Schema.org JSON-LD type matches page intent
- [ ] Canonical URL set to avoid duplicate content
- [ ] Mobile-responsive design verified
- [ ] Page load <3 sec (Core Web Vitals)
- [ ] Open Graph tags for social sharing

## Long-tail keyword discovery process

### Monthly cadence

- Google Search Console: Top 50 queries past 28 days
- Identify queries showing impressions but no rank (opportunity)
- Manually validate intent + create targeted page if absent
- Update existing page if rank position 4-15 (push to top 3)

### Per-quarter audit

- Backlinks-monitor agent reports (per existing fleet)
- Competitor keyword overlap analysis
- Internal linking gaps identified
- Content gap analysis (topics with high intent + no Bhaktisetu page)
