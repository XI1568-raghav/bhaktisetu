# YouTube Channel — Weekly Live Darshan + How-To-Puja Content

> **Roadmap item**: R-Q2-M-009 (P1) · **Authored**: 2026-06-13

## Goal

Q2 launch Bhaktisetu YouTube channel. Weekly live darshan recordings + how-to-puja explainer content. Targets 1K subs + 10K monthly views Q2-end.

## Channel setup

- Name: "Bhaktisetu Official"
- Handle: @bhaktisetu
- Banner: brand banner w/ logo + tagline
- About: 2-line description + bhaktisetu.com link
- Verified link: founder personal LinkedIn

## Content cadence (4-5 videos/week)

### Daily (Mon-Fri)
- 60-sec aarti reels (cross-posted from Instagram per R-Q2-M-004)
- Auto-pushed to Shorts shelf

### Weekly (2 long-form)
1. **Live darshan recording** — Tuesday 12:00 IST
   - 15-30min curated highlight from week's live aarti streams
   - Per-temple variety (rotate Kashi/Mahalakshmi/ISKCON/etc)
2. **How-to-puja explainer** — Saturday 12:00 IST
   - 10-15min "How to do X puja at home"
   - Real pandit-led, scriptural references
   - Cross-link to /pujas/{slug} in description

### Monthly (1 long-form)
- "Bhaktisetu Q&A" — founder + pandit panel
- 30min, community-asked questions
- Boost subscriber retention

## SEO

- Keyword research: "live aarti", "how to do rudrabhishek", "kashi vishwanath darshan today"
- Descriptions: 250 words w/ scriptural citations + Bhaktisetu link
- Tags: 15+ per video
- Custom thumbnails: high-contrast saffron + Devanagari + face

## Monetization (post 1K subs + 4K watch-hours)

- YouTube partner program (deferred Q3 once thresholds met)
- Affiliate links to Bhaktisetu products in description
- "Sponsored by Bhaktisetu" cards (allowed)
