## Production notes

- Use a real screenshot, not a mock. PH community detects fake screenshots and downvotes.
- Keep file size under 1MB per image (PH renders faster, better mobile experience).
- Test on mobile: open the 4 images on a phone, confirm text is readable at thumbnail size.
- Save originals as PNG. Do not use JPEG for UI screenshots (artifacts on text).
