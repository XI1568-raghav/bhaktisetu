## Why a separate target list

The Phase-0 deck (`csr-match-campaign.md`) targets 10 IT/BFSI **operating companies** via their corporate CSR head (Srinivasan@TCS, Parag Rao@HDFC, etc.). That's the right path for direct CSR Schedule VII Item III pitches.

This kit targets the 10 **independent Foundation arms** of the same parent groups. Foundations have:
- separate boards, independent of corporate-CSR committee
- explicit charitable-trust mandate (often broader than parent CSR Schedule VII filters)
- typically warmer to **partnership** asks (vs single-cheque CSR allocations)
- monthly/quarterly grant cycles vs annual CSR-committee gating
- usually CSR-1 + 80G compatible by default

Hit both tracks in parallel. If TCS Foundation says no, TCS corporate CSR head is still in play (and vice versa).

## B. Pitch email template

**Subject:** `2x match opportunity — Navratri/Diwali adopt-a-temple campaign (80G + monthly impact reports)`

**Body (152 words):**

```
Hi {{founder_first_name_of_foundation_director}},

I'm {{founder_first_name}}, founder of Bhaktisetu — India's verified-temple
adopt-a-temple platform. Reaching out because {{partner_name}}'s work on
{{recent_csr_initiative}} aligns with what we're proposing for Navratri/Diwali 2026.

The ask: a 2x corporate match on employee adopt-a-temple subscriptions during
the festival window. Employees pledge ₹500-5000/month per temple, Foundation
matches 2x, total flows monthly to verified temples on 80G rails.

Your benefit: every donor gets an auto-issued 80G receipt + a monthly impact
PDF showing exactly which temple their funds reached and what was sustained
(priest stipend, daily pujas, repair line-items). Co-mention possible on
landing page and donor reports.

Proof: Bhaktisetu Foundation holds active 80G + CSR-1, MoU template ready.
Current donor base + GMV available on request.

Open to a 15-min call this week or next? Calendar: {{founder_calendly_link}}.

Best,
{{founder_first_name}}
```

**Personalization tokens:**

| token | source | notes |
|---|---|---|
| `{{partner_name}}` | Section A column 2 | exact Foundation arm name, not parent (use "Infosys Foundation" not "Infosys") |
| `{{csr_focus_area}}` | Foundation's stated focus areas | one of: education / healthcare / rural-dev / arts-culture / heritage |
| `{{recent_csr_initiative}}` | last 6mo press / annual report | concrete project name, not generic ("Akshardham preservation grant" not "temple work") |
| `{{founder_first_name}}` | constant | from founder profile |

**Word count budget:** 130-170 words. Current draft: 152 ✓. Reject any longer.

**Tone rule:** Foundation directors get ~30-50 cold emails/week. First sentence MUST signal you read their work (the `{{recent_csr_initiative}}` token does this). Generic openers go to trash.

## C. Tracking sheet schema

> **Schema only.** Live sheet creation is founder action (Google Sheets recommended over Airtable for free tier). Founder owns the tracker — agents do NOT write to live sheets.

| column | type | notes |
|---|---|---|
| partner_name | text | from Section A; exact Foundation name |
| contact_name | text | founder fills after Foundation-Director research (LinkedIn / Foundation website) |
| contact_email | text | founder fills; NeverBounce verify before send |
| contact_role | text | "Foundation Director" / "CEO" / "Head of Programs" |
| status | enum | `cold` → `emailed` → `meeting` → `signed` → `active` (one-way progression; on dead-end mark `cold-dead`) |
| first_touch_date | date | day of first cold email send |
| last_touch_date | date | day of last interaction (email, call, follow-up) |
| match_committed_inr | int | 0 until MoU signed; populated from signed MoU terms |
| period | text | `Navratri-2026` / `Diwali-2026` / `Holi-2027` |
| notes | text | free-form; objections, asks, next-step commitments |

**Optional cols if founder wants tighter funnel tracking:**
- `meeting_count` (int)
- `decision_maker_identified` (bool) — true once we have confirmed budget-holder name
- `objection_primary` (enum: budget / timing / scope / 80G-doubt / other)

## D. Founder-action checklist (this week)

```markdown
- [ ] Verify CSR budget data for all 10 partners (BRSR reports — Section A annual_csr_budget_inr column)
- [ ] Fill warm_intro_path column for each (LinkedIn 2nd-degree check, prior employer overlap, alumni network)
- [ ] Create live tracking sheet (Google Sheets, schema from Section C — DO NOT delegate to agents)
- [ ] Personalize email template for top-5 priority partners (P0 first: Infosys Foundation, Reliance Foundation, Tata Trusts, Adani Foundation)
- [ ] Send 5 cold emails (manual, from founder@ inbox, NOT bulk tool / NOT Resend / NOT Mailchimp — Foundation directors block bulk)
- [ ] Schedule 7-day follow-up reminder in calendar for each cold email sent
- [ ] Update item handoff_notes after first reply received (positive OR negative — both are signal)
```

**Sequencing rationale:**
1. Verify-data first because false budget numbers in the pitch kill credibility.
2. Warm-intro check second — every warm intro raises reply rate 4-8x.
3. Live sheet before sending because tracking without a system collapses by week 2.
4. Personalize ONLY top-5 to start. Don't blast all 10 — quality first.
5. Manual send from `founder@` because anything from a tracking domain (Mailchimp, HubSpot) gets greylisted on Foundation inboxes that have stricter spam filters.
