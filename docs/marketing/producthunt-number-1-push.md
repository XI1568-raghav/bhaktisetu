# ProductHunt #1 Push — Launch-Day Campaign + Hunter Outreach

> **Roadmap item**: R-Q4-M-001 (P0) · **Authored**: 2026-06-13 · **Extends**: docs/marketing/producthunt-launch-playbook.md (R-Q2-M-001 v1)

## Goal

Q4 PH push targets **#1 Product of the Day** (not just top 10). Stretch target: also top 5 Product of the Week.

## Why ramp from top-10 to #1

- Top 10 = ~3K visits, ~150 upvotes, organic traffic
- #1 = ~15K visits, ~500 upvotes, PRESS PICKUP (TechCrunch, Inc42 auto-cover top-3 daily)
- ROI: #1 push needs 4-5x hunter mobilization but yields 5-10x downstream signups + press value

## Coordinated push tactics

### T-21 days

```markdown
- [ ] Identify launch date (Tuesday or Wednesday early Q4 — recommend Oct 7, 2026 — pre-Diwali demand window)
- [ ] Reach 100 PH hunters (vs 20 in v1) — DM personal note per hunter, leverage prior connections
- [ ] Pre-warm 5 PH "top makers" (people w/ 1000+ followers) for boost-comment day-of
- [ ] Coordinate w/ 5 Indian devotional micro-influencers for IG/Twitter cross-promo
- [ ] Pre-warm 10 India tech journalists for embargoed press release
- [ ] Schedule launch-day social posts across 8 channels
```

### T-7 days

```markdown
- [ ] Refresh PH page assets w/ Q3-actuals data (MAU, MRR, temples count)
- [ ] Record updated 60s demo video (showing real customer reviews)
- [ ] Build "PH launch deal" — first 100 Bhaktisetu customers from PH get ₹100 wallet credit
- [ ] Draft Twitter thread (10 tweets) for launch day, schedule first 2
- [ ] LinkedIn long-post draft (1000 words founder story)
```

### Launch day

```markdown
- [ ] 12:01 AM PT (12:31 PM IST): GO LIVE
- [ ] T+5min: first-comment-in-thread (founder pinned)
- [ ] T+15min: tweet thread sequential post (1 every 30 min for 5 hours)
- [ ] T+30min: LinkedIn long-post
- [ ] T+1hr: IG carousel + IG story w/ countdown
- [ ] T+2hr: WA blast 50 close contacts
- [ ] T+3hr: Reddit r/IndianStartup + r/bangalore + r/hinduism (3 separate posts)
- [ ] T+4hr: check PH ranking; if outside top 5, mobilize 2nd wave hunters
- [ ] T+6hr: send press releases (5 tech journos)
- [ ] T+8hr: check ranking; if top 3, write "we're at #X!" tweet
- [ ] T+12hr: mid-day standing
- [ ] T+24hr: final standing tweet + thanks
```
