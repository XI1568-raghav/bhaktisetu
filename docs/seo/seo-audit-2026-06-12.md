### 4. IndexNow integration (LOW risk, can ship next cycle)

[IndexNow](https://www.indexnow.org/) is the cross-engine instant-indexing protocol (Bing + Yandex + Naver — Google doesn't support directly but Bing+Yandex are ~10% of India search). Free to use.

**Implementation pattern**:

```typescript
// apps/api/src/lib/seo/indexnow.ts
const INDEXNOW_KEY = process.env.INDEXNOW_KEY;
const INDEXNOW_KEY_LOCATION = 'https://darshya.online/' + INDEXNOW_KEY + '.txt';

export async function submitToIndexNow(urls: string[]): Promise<void> {
  if (!INDEXNOW_KEY) return; // graceful no-op per env-or-noop pattern
  const res = await fetch('https://api.indexnow.org/IndexNow', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      host: 'darshya.online',
      key: INDEXNOW_KEY,
      keyLocation: INDEXNOW_KEY_LOCATION,
      urlList: urls,
    }),
  });
  // Best-effort. Log non-200 but don't throw.
}
```

Trigger points:
- New temple added → submit `/temples/{slug}`
- New puja type added → submit `/puja/{slug}`
- New blog post → submit `/blog/{slug}`
- New festival page → submit `/festivals/{slug}` (post R-Q4-E-011 ship)

**Engineering ticket name**: R-Q3-E-ZZZ (file next cycle) — "IndexNow submission on content-publish events"

**Founder action**: generate `INDEXNOW_KEY` (random 32-char hex), host `/{key}.txt` file at site root, paste env to CF Pages.
