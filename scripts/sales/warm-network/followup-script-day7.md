# Day-7 follow-up script

> Send ONCE, 7 days after initial WA/email if no reply received.
> If still silent after this: log `replied_at: silent` and STOP. Asking three times damages the relationship.

## Hindi

{first_name} bhai/ji, soft nudge — pichle hafte ki message dekhi hogi? Koi pressure nahi, bas pucha. Agar kuch mind mein nahi hai toh "nahi" likh do, main move on kar dunga. 🙏

## English

{first_name} — soft nudge in case my last message got buried. No pressure at all. If nothing comes to mind, just send "no" and I'll move on. 🙏

## Notes

- Replace `{first_name}`. Vary nothing else.
- Reply types to log: positive (referral_received: yes) / negative (referred: no, status: closed) / silent (after this nudge, mark `replied_at: silent`).
- Never send a third message. Wait 6 months minimum before any next ask.
